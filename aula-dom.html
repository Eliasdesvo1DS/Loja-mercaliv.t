HTML + JAVASCRIPT

Aula DOM

Explore exemplos simples de como o JavaScript encontra e altera elementos de uma página.

O que é DOM?DOM é a representação da página HTML que o JavaScript pode consultar e modificar, por exemplo, alterando textos, listas, imagens e estilos.
